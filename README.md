# Swiss System with bbpPairing
This is a tournament manager, made mostly for local use.

## Building

### Prerequisites

- `make` and a C++ compiler. The Makefile is set to `g++-15` (see `CC` in the
  Makefile); change it if your compiler is named differently.
- [SDL2](https://www.libsdl.org/) development libraries.
- `git`, to fetch the submodules.

On macOS with Homebrew:

```sh
brew install sdl2 gcc make
```

### 1. Clone with submodules

Dear ImGui and ImGuiFileDialog are git submodules, so `external/` will be empty
after a plain clone:

```sh
git clone --recurse-submodules https://github.com/<your-fork>/Bilkent-Swiss.git
```

### 2. Build the pairing engine

Pairings are generated by [bbpPairings](https://github.com/BieremaBoyzProgramming/bbpPairings),
which is a separate program that is not bundled with this repository. Build it
and copy the resulting binary into `bin/`:

```sh
git clone https://github.com/BieremaBoyzProgramming/bbpPairings.git
cd bbpPairings
make COMP=gcc CXX=g++-15 CXXFLAGS='$(optional_cxxflags) -Wno-error'
cp bbpPairings.exe /path/to/Bilkent-Swiss/bin/
```

Notes on that `make` line:

- `COMP` selects the compiler *family* (`gcc` or `clang`); the actual compiler
  comes from `CXX`. Setting only `COMP` will still invoke your default `c++`.
- bbpPairings builds with `-Werror` and a large warning set. Recent compilers
  emit advisory warnings it does not expect, so the build fails without
  `-Wno-error`. Overriding `CXXFLAGS` as shown re-expands its own flag list and
  appends the flag, leaving its Makefile untouched.

The file is named `bbpPairings.exe` on every platform, and this program expects
it at `./bin/bbpPairings.exe`.

### 3. Build and run

```sh
make
./bin/main
```

Run `./bin/main` from the project root: the pairing engine and its temporary
files (`out.trf`, `round.txt`) are referenced by relative path.
